# A Little Birthday Universe 🎀
Static site (HTML/CSS/JS, no build). Sửa toàn bộ chữ trong `js/content.js`.
Optional music: add `assets/music/birthday.mp3` (site works without it).

## Deploy on GitHub Pages
1. GitHub → New repository → name `birthday-for-linh` → Public → Create.
2. "uploading an existing file" → drag the CONTENTS of this folder (index.html, css, js, assets, README.md) → Commit.
3. Settings → Pages → Source: "Deploy from a branch" → Branch `main` / `(root)` → Save.
4. Wait ~1–2 minutes → open `https://<username>.github.io/birthday-for-linh/`.
5. Check: all 7 screens, Replay, and on a phone (no sideways scroll).
